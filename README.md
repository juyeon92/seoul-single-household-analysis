# 서울 1인가구 관심사 기반 취약지역 분석

서울시 1인가구 데이터를 기반으로 자치구별 생활 취약도를 분석하고, 사용자가 선택한 관심사 가중치에 따라 취약지역을 재계산·시각화하는 데이터 분석형 웹 프로토타입입니다.

본 프로젝트는 단순히 1인가구 수가 많은 지역을 보여주는 것이 아니라, 주거불안·경제불안·생활안전·건강관리·고립·돌봄/응급 등 6대 생활 관심사를 기준으로 지역별 취약 신호를 복합적으로 해석하는 것을 목표로 합니다.

---

## 프로젝트 목적

서울의 1인가구는 세대별로 다른 생활 문제를 가지고 있습니다.

청년층은 주거비 부담과 생활안전, 중장년층은 경제불안과 건강관리, 노년층은 돌봄·응급 대응과 고립 문제가 상대적으로 중요하게 나타납니다.

이 프로젝트는 공공데이터를 기반으로 각 자치구의 취약도를 정량화하고, 정책 개입이 우선적으로 필요한 지역을 시각적으로 탐색할 수 있도록 설계했습니다.

---

## 핵심 문제 정의

기존의 지역 통계는 개별 지표 중심으로 제공되어 다음과 같은 한계가 있습니다.

- 1인가구 수는 확인할 수 있지만, 실제 생활 취약도를 함께 보기 어려움
- 세대별로 다른 정책 니즈를 반영하기 어려움
- 주거, 안전, 고립, 건강 등 여러 지표를 종합적으로 비교하기 어려움
- 데이터 분석 결과를 일반 사용자가 직관적으로 이해하기 어려움

따라서 본 프로젝트에서는 공공데이터를 6대 관심사 기준으로 재구성하고, 복합점수·지도·순위·유형분석을 통해 정책 우선순위를 쉽게 파악할 수 있도록 했습니다.

---

## 분석 기준

본 프로젝트는 서울시 25개 자치구를 기준으로 분석했습니다.

### 6대 관심사

| 관심사 | 주요 해석 |
|---|---|
| 주거불안 | 월세환산 주거비, 거처 취약성, 전월세 전환율 |
| 경제불안 | 기초생활보장 수급률, 경제지원 접근성 |
| 생활안전 | 5대 범죄, CCTV, 안심귀갓길 등 생활안전 인프라 |
| 건강관리 | 보건·복지 접근성, 건강관리 취약 신호 |
| 고립 | 관계망 프로그램 접근성, 사회적 관계망 취약 신호 |
| 돌봄/응급 | 재가노인복지시설, 노인여가시설, 고령 독거노인 비율 |

---

## 주요 기능

### 1. 세대별 1인가구 분포 확인

서울시 자치구별 1인가구 분포를 전체·청년·중장년·노년 기준으로 확인할 수 있습니다.

이를 통해 단순 취약도 분석 전에 정책 대상 규모가 큰 지역을 먼저 파악할 수 있습니다.

---

### 2. 관심사별 취약지도

6대 관심사별로 자치구의 취약도를 지도 기반으로 시각화했습니다.

사용자는 주거불안, 경제불안, 생활안전, 건강관리, 고립, 돌봄/응급 중 하나를 선택해 각 지역의 상대적 취약 수준을 확인할 수 있습니다.

---

### 3. 사용자 가중치 기반 취약지역 재계산

사용자가 관심사별 가중치를 조정하면 지도, TOP 순위, 점수 구성 그래프, 세대별 취약지역, PCA 시각화가 함께 재계산되도록 설계했습니다.

이를 통해 하나의 고정된 분석 결과가 아니라, 정책 목적이나 사용자 관심사에 따라 다른 우선순위를 탐색할 수 있습니다.

---

### 4. 세대별 취약지역 분석

청년·중장년·노년별로 중요 관심사를 다르게 적용하여 세대별 취약지역을 도출했습니다.

예를 들어 청년은 주거불안과 생활안전, 중장년은 경제불안과 건강관리, 노년은 돌봄/응급과 고립 신호가 더 중요하게 반영됩니다.

---

### 5. KMeans 기반 취약유형 분류

서울시 25개 자치구를 KMeans 방식으로 3개 취약유형으로 분류했습니다.

| 유형 | 설명 |
|---|---|
| 도심 주거부담형 | 주거비 부담이 높고 중심권 특성이 강한 지역 |
| 전세대 복합취약형 | 생활안전, 건강관리, 세대별 취약도가 함께 높은 지역 |
| 경제·노년돌봄 취약형 | 경제불안, 고립, 건강관리, 돌봄 공백이 두드러지는 지역 |

---

### 6. PCA 기반 취약유형 시각화

KMeans로 분류된 자치구 유형을 PCA 산점도로 시각화했습니다.

이를 통해 각 자치구가 어떤 취약유형에 가까운지, 유형 간 거리가 어떻게 나타나는지 직관적으로 확인할 수 있습니다.
